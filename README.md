# Personal Expense Tracker with CSV

A beginner-friendly Python CLI application for recording and managing daily expenses using CSV file storage.

## Features

- Add daily expenses
- View all expenses
- Filter expenses by category
- Calculate category-wise expense summaries
- Calculate total expenses
- Persistent CSV-based data storage
- Input validation for expense amounts

## Technologies Used

- Python 3
- CSV module
- File handling
- Functions
- Loops
- Conditional statements
- Dictionaries
- Exception handling

## CSV Structure

The application stores expenses in the following format:

| Date | Category | Description | Amount |
|---|---|---|---|
| 29-09-2026 | Food | Lunch | 250 |
| 29-09-2026 | Transport | Auto | 120 |

## How to Run

```bash
python expense_tracker.py
